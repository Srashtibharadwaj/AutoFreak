
# AutoFreak 🚗

## 📌 Overview
**AutoFreak** is a Django-based web application built to manage and organize automobile-related information through a centralized and scalable platform.  
The project follows Django’s **MVT (Model–View–Template)** architecture and is designed with clean structure, maintainability, and real-world usability in mind.

It is suitable for **academic projects, backend development learning, and production-ready system design**.

---

## 🌍 Real-World Problem Statement
In the automobile domain, many small service providers and users rely on:
- Manual record keeping  
- Unstructured data storage  
- Inefficient workflows  

These issues lead to **data loss, poor scalability, and time-consuming management**.

AutoFreak addresses this problem by providing a **digital, centralized, and structured web-based solution** for managing automobile-related data efficiently.

---

## 🚀 Key Features
- Django-based backend using MVT architecture  
- Modular app structure for scalability  
- Dynamic content rendering with templates  
- Organized static asset management  
- Centralized data handling using Django ORM  
- Clean separation of business logic and UI  

---

## 🛠 Technology Stack
- **Backend:** Python, Django  
- **Frontend:** HTML5, CSS3, Django Templates  
- **Database:** SQLite (development)  
- **Tools:** Git, GitHub, VS Code

## 🧩 System Architecture

```text
User (Browser)
      ↓
Django Templates (UI Layer)
      ↓
Django Views (Business Logic)
      ↓
Django Models (ORM)
      ↓
Database (SQLite)
      ↓
Admin Panel
```

## ⚙️ How to Run the Project
1. Clone the repository  
2. Create and activate a virtual environment  
3. Install dependencies using `pip install -r requirements.txt`  
4. Run the server using `python manage.py runserver`
